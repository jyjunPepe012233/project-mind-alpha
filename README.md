# 밀러의 마법 (Project MinD, Magician In Dungeon)

**기간:** 2024.08. ~ 2025.05.  

## 프로젝트 소개

**판타지 월드를 탐험하는 액션 어드벤처 게임!**

순간이동, 방어마법 등의 조작을 활용해 던전을 돌파하고 던전 끝에 위치한 보스에 도달하는 플레이  
던전의 퍼즐을 풀고, 숨겨진 마법들을 찾아 주인공을 막아서는 적들을 제압하자.

<img width="8139" height="4945" alt="Wallpaper(2930_1780)-1" src="https://github.com/user-attachments/assets/ed7378ff-7d65-4736-baa1-00bc7d4e6618" />

### 특징
- 오프라인 싱글 플레이어
- 액션 어드벤처 RPG
- PC 플랫폼(Window, MacOS)
- Switch Pro Controller 조작 지원

## 주요 기능

| 구분 | 세부 기능 목록 |
|---|---|
| **전투 및 조작** | 키보드·마우스 및 게임패드 조작 지원, 순간이동(대시), 방어 마법, 공격 마법, 락온 타겟팅 |
| **장비** | 무기, 방어구, 탈리스만, 소모품 |
| **월드** | 안개마을 조각상(퍼즐), 중간 보스, 최종 보스 |
| **UI** | 인벤토리 메뉴, 퀵슬롯 HUD, 튜토리얼 팝업, 버스트 팝업(You Died) |

## 발표 자료 (개발 버전 당시)

이 자료는 개발 버전의 내용입니다.  

현재 밀러의 마법은 알파 버전으로, 실제 필드와 보스가 추가되었고 그래픽 및 모델링 품질도 개선되었습니다.
